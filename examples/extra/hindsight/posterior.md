# Experimental on-policy hindsight estimators

Use the experimental estimators on fixed-horizon, goal-independent tasks when the environment knows the true goal prior and the actor records replayable legal support, processed action log probabilities and a single immutable behavior version. Each likelihood must use the exact collecting policy, sampling temperature, legal actions and token context.

Call `make_posterior_targets(episodes, worlds, goal_priors, snapshot, score_frozen, rng)` from `prime_rl.orchestrator.posterior_hindsight`. Each prior is conditioned on its starting state and must be positive exactly on the ordinary world’s supported goals. On a miss, the factual goal is the foil. On a hit, sample a foil from the original prior conditional on excluding the achieved goal. The callback scores one batch of alternative paths, returning one conditional log probability per real action in each path. If the achieved goal has prior mass `q` and the path has likelihoods `p_y` and `p_j` under the achieved and foil goals, the posterior is `w = q*p_y / (q*p_y + (1-q)*p_j)`.

- For the zero-baseline update, score the eligible achieved paths with fresh activations. Call `weighted_hindsight_loss(achieved_logp, posterior, len(episodes))` from `prime_rl.trainer.rl.posterior_hindsight`. Each path log probability is the sum over its actions.
- For a centered update call `centered_update_loss(targets, snapshot, score_student, baseline)` from the orchestrator module. The differentiable callback returns one summed path log probability per supplied context. A baseline fixed before the action draw and shared by both goals gives the score `w*(1-b)*grad(log p_y) - (1-w)*b*grad(log p_j)`. The router normalizes the achieved and foil probabilities separately. This preserves a small foil contribution even when the achieved probability rounds to one. A zero-prior achievement retains its factual foil contribution. A singleton-prior hit retains its factual achieved contribution.

In both estimators, one gradient evaluation at the collecting parameters estimates the original terminal-reward policy gradient. Repeated optimization on these frozen targets changes the objective. Both require extra counterfactual model work. The example's ordinary imitation objective remains the model-quality baseline.
